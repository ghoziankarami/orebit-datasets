# Latihan tambahan: survey dan QA/QC

Gunakan salinan/project baru. [Survey melengkung](deviated-survey/README.txt) menguji Minimum Curvature pada3lubang,12station dan midpoint interval. [QA/QC](qaqc-synthetic/README.txt) mengajarkan kontrol simulasi SIMNI/blank/duplicate dan failure yang memang disengaja. Dataset utama serta tonase pair/loft tetap dipatok; hasil tambahan tidak dicampur dengan bukti baseline vertikal.

Semua data sintetis, CC BY4.0, Ghozian Karami/Orebit.id. Grade/litologi subset survey berasal dari dataset workshop; arah survey baru adalah skenario pengajaran. Tidak ada certificate/hasil lab nyata atau sign-off profesional. File expected adalah oracle untuk pengujian, bukan tabel input estimasi.
